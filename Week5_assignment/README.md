# Week 5 — Data Cleaning & Spark Fundamentals

**Celebal Summer Internship 2026 | Data Engineering Track**

---

## Objective

Understand Spark fundamentals and perform data cleaning, transformation, and aggregation using PySpark DataFrames.

## Topics Covered

- Limitations of MapReduce and advantages of Spark
- In-memory computing and iterative ML
- Handling nulls and duplicates
- Filtering and compound conditions
- GroupBy and aggregation functions
- Wide transformations and shuffle
- Schema casting and column renaming
- Building a complete data processing pipeline

## Files

| File | Description |

| `Week5_Theory.docx` | Written answers for conceptual questions (Q1, Q2, Q5, Q7, Q9, Q11, Q14) |

## Dataset

A synthetic dataset of 600 rows was generated with 14 columns including `user_id`, `transaction_date`, `region`, `product_category`, `sale_amount`, `city`, `age`, `subscription`, `email`, `username`, `price`, `raw_timestamp`, `store_id`, and `status`. Intentional nulls and duplicates were introduced to simulate real-world data quality issues.

- Python 3.12
